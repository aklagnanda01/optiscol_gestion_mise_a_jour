# OptiScol — mises à jour du poste

Ce dépôt ne contient **aucun code** : il publie seulement les versions de
l'application de bureau OptiScol (installateurs Windows, macOS, Linux AppImage)
et le fichier `latest.json` que les postes installés consultent pour se mettre
à jour automatiquement.

Les versions sont publiées par la chaîne de construction du dépôt de
l'application (privé), à chaque tag `vX.Y.Z`. Ne rien publier ici à la main.
